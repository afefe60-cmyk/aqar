# SudanZon Real Estate (سودان زون للعقارات والأراضي)

المنصة الرقمية المتكاملة لبيع، شراء، وتأجير العقارات، الأراضي، الفنادق وإدارة الأملاك في السودان — المشروع الثالث ضمن **منظومة سودان زون الرقمية (SudanZon Ecosystem)**.

---

## 🌟 الميزات والخدمات الرئيسية (Features):
* **تصفح وبحث عقاري ذكي:**
  - فلاتر جغرافية تفاعلية بكافة المدن والولايات السودانية (بورتسودان، شندي، مروي، عطبرة، الخرطوم وغيرها).
  - تصنيفات شاملة: عقارات للبيع، عقارات للإيجار، أراضي ومخططات سكنية وزراعية، شقق مفروشة، فلل، وعمارات كاملة.
  - تسعير حصري بالجنيه السوداني (ج.س / SDG) مع شارات توثيق شهادات البحث.
* **معرض صور تفاعلي متقدم:**
  - عرض صور عالية الدقة لزوايا وغرف العقار مع أزرار تنقل تفاعلية وشريط صور مصغرة موسّع.
* **فنادق وشقق فندقية مجهزة (Hotels & Stays):**
  - استعراض وحجز الشقق الفندقية المفروشة مع ميزات خاصة كالكهرباء المتواصلة عبر المولدات 24 ساعة وإنترنت ستارلينك الفضائي.
* **خدمة إدارة الأملاك والعمارات (Property Management):**
  - باقات مخصصة للمغتربين وأصحاب الأملاك (التحصيل والتأجير، الصيانة الدورية، الإشراف الفني وإيداع الإيجارات عبر الحسابات البنكية وتقارير موثقة).
* **دليل المكاتب والشركات العقارية (Agencies Directory):**
  - شبكة موثقة للوكالات العقارية المعتمدة في مختلف مدن السودان.
* **تواصل فوري ومباشر:**
  - ربط مباشر عبر الواتساب والمكالمات الهاتفية مع المالك أو المكتب دون عمولات خفية.
* **جاهزية تطبيق الهاتف (Capacitor / Android Ready):**
  - معرف الحزمة المعتمد: `com.sudanzon.realestate`.

---

## 🛠 التقنيات المستخدمة (Tech Stack):
* **الواجهة الأمامية:** Next.js 14 + React 18
* **التصميم والخطوط:** Tailwind CSS + Google Fonts (Cairo & Tajawal) + Lucide Icons
* **تطبيق الهاتف:** @capacitor/core + @capacitor/android
* **الباك إند وقاعدة البيانات المشتركة:** Node.js + Express + Prisma ORM + MySQL

---

## 🚀 التشغيل المحلي (Getting Started):

```bash
# تثبيت الحزم (إن لم تكن مثبتة مسبقاً)
npm install

# تشغيل خادم التطوير على المنفذ 3004
npm run dev
```

افتح المتصفح على: [http://localhost:3004](http://localhost:3004)
